# AI Issue Scope Guard

Vue 3 + TypeScript learning project for checking whether AI-generated pull requests stay within the original GitHub Issue scope.

This repository is currently in the bootstrap phase. Issue #2 only creates the project scaffold, base routes, layout shell, styles, and test setup.

## Tech Stack

- Vue 3
- Vite
- TypeScript
- Vue Router
- Pinia
- Vitest
- Testing Library
- npm

## Local Setup

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run build
npm run test
```

## Current Routes

- `/` - Landing placeholder
- `/checker` - Scope checker placeholder
- `/rules` - Rule explanation placeholder

## Scope Notes

This bootstrap does not implement checker UI, analyzer logic, example data, persistence, API integration, auth, database integration, or deployment configuration.
